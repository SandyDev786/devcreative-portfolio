📁 Image Storage Guide

How to properly organize images and videos for your portfolio

✅ Recommended Method: Image Folder

For GitHub hosting, use a dedicated images folder!

This is cleaner, faster, and works better for professional portfolios.

📂 Folder Structure

Create this folder structure in your portfolio:

portfolio/
├── images/
│ ├── hero/
│ │ ├── hero-background.jpg
│ │ └── hero-video.mp4
│ ├── about/
│ │ └── my-photo.jpg
│ └── projects/
│ ├── project-1/
│ │ ├── cover.jpg
│ │ ├── gallery-1.jpg
│ │ ├── gallery-2.jpg
│ │ └── gallery-3.jpg
│ ├── project-2/
│ │ ├── cover.jpg
│ │ └── gallery-1.jpg
│ └── project-3/
│ └── cover.jpg
├── admin-login.html
├── admin-dashboard.html
├── index.html
└── project-detail.html

🎯 How to Use Images from Folder

Option 1: During Upload (Recommended)

  1. First, create the images folder structure
  2. Upload your images to the appropriate folders
  3. In the CMS, instead of clicking "Upload", enter the image path manually

Example Paths:

Cover Image: images/projects/project-1/cover.jpg
Gallery Image 1: images/projects/project-1/gallery-1.jpg
Gallery Image 2: images/projects/project-1/gallery-2.jpg
Hero Background: images/hero/hero-background.jpg
Your Photo: images/about/my-photo.jpg

Option 2: Use the Current System (Base64)

  1. Upload images directly in the CMS (current method)
  2. Images are stored as base64 in browser localStorage
  3. Pros: Easy, no folder setup needed
  4. Cons: Large file sizes, localStorage limits (~5-10MB)

⚙️ Setting Up for GitHub

Step 1: Organize Your Files Locally

  1. Create images folder in your portfolio folder
  2. Create subfolders: hero, about, projects
  3. Place your images in the correct folders
  4. Name them clearly: project-1-cover.jpg, project-1-gallery-1.jpg

Step 2: Update Image Paths in CMS

In the admin dashboard, I'll add an option to use image URLs instead of uploading.

Step 3: Upload Everything to GitHub

  1. Upload all HTML files
  2. Upload the entire images folder with all subfolders
  3. Enable GitHub Pages
  4. Your images will load from the folder!

📸 Image Optimization Tips

Before Uploading to GitHub:

  • Compress images: Use tinypng.com (free)
  • Cover images: 1200x800px, under 500KB
  • Gallery images: 1920x1080px, under 1MB each
  • Hero background: 1920x1080px, under 1MB
  • Videos: Under 10MB, MP4 format
  • File names: Use lowercase, hyphens, no spaces

🔄 Two Workflows

Workflow A: Image Folder (Recommended for GitHub)

1. Create images folder structure
2. Add your images to folders
3. In CMS, enter image paths like: images/projects/project-1/cover.jpg
4. Upload everything to GitHub including images folder

1. Use CMS upload buttons
2. Images stored in browser localStorage as base64
3. Upload only HTML files to GitHub
