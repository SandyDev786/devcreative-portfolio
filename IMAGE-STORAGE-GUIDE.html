Portfolio CMS Hosting Guide

This version saves CMS data and uploaded files on the hosting account using PHP.

Required Hosting

Use any standard hosting account that supports PHP file uploads, including Namecheap shared hosting. Pure static hosts cannot save uploaded files without a backend.

Files To Upload

Upload the whole project folder to your hosting document root, usually public_html.

admin-login.html
admin-dashboard.html
cms-api.php
cms-client.js
github-upload-config.js
index.html
project-detail.html
data/
images/

Writable Folders

The PHP API writes to these folders:

data/cms-data.json
images/hero/
images/about/
images/projects/

If uploads or saves fail on shared hosting, set data and images to writable in cPanel File Manager.

How It Works

  • Admin login creates a PHP session.
  • Project and homepage content is saved in data/cms-data.json.
  • Uploaded images are stored inside images.
  • The public pages load the JSON data from cms-api.php.
  • If PHP is unavailable during local testing, the site falls back to browser storage.

Admin Credentials

The default credentials are still admin / admin123. Change them in cms-api.php before going live.
